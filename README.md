# DieRoller 🎲

A lightweight, command-line dice roller designed for tabletop RPGs (like D&D) and board games. It supports complex dice expressions including multiple dice, specific die types, and positive/negative modifiers.

## ✨ Features

- **Flexible Expressions**: Input rolls like `3d6+2`, `1d20-1`, or just `2d10`.
- **Modifier Support**: Automatically handles both addition and subtraction modifiers.
- **Input Validation**: Ensures correct formatting, valid die types (1-100), and non-negative dice counts.
- **Clean Output**: Displays the individual results of every die rolled along with the final total.
